# Analyzing TV data: the Super Bowl

- **Goal:** find out how game outcomes, TV viewership and halftime shows relate across 50+ years of Super Bowls.
- **Data:** `super_bowls.csv` (scores), `tv.csv` (audience and ad costs), `halftime_musicians.csv` (performers), scraped from Wikipedia.
- **Method:** exploratory analysis with pandas (merges, groupby) and matplotlib/seaborn visualisations.

Notebook: [`analyzing-tv-data.ipynb`](analyzing-tv-data.ipynb) · based on a DataCamp guided project.
