# Generating keywords for Google Ads

- **Goal:** build a prototype keyword list for a furniture retailer's search campaigns (sofas, convertible sofas, love seats, recliners, sofa beds).
- **Data:** none — the products and the discount-oriented modifiers come from the brief inside the notebook.
- **Method:** combine products and modifiers in both word orders with Python, shape the result into an Ad Group / Keyword / Match type table with pandas, and export it as CSV.

Notebook: [`generating-keywords-for-google-ads.ipynb`](generating-keywords-for-google-ads.ipynb) · based on a DataCamp guided project.
