# Wrangling and visualizing musical data

- **Goal:** see which chords and chord progressions pop/rock artists favour, and whether guitarists and pianists differ.
- **Data:** `bb_chords.csv` — professionally annotated chords from the McGill Billboard dataset (Billboard Hot 100 singles, 1958–1991).
- **Method:** R — data wrangling with dplyr (chord counts, bigrams of consecutive chords) and ggplot2 charts comparing instruments.

Notebook: [`wrangling-and-visualizing-musical-data.ipynb`](wrangling-and-visualizing-musical-data.ipynb) (R kernel) · based on a DataCamp guided project.
